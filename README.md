# S.P.R.E.A.D.

### System for Processing, Routing, Equipment, Allocation, and Distribution

S.P.R.E.A.D. is a relational database project designed to track foodborne outbreaks through the food supply chain.

The system connects reported illness cases with food products, shipments, distributors, and suppliers to help identify the potential source of contamination.
